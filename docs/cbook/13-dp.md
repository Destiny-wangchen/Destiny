动态规划听起来吓人，本质只有一句话：**同一个子问题不要算第二遍**。能拆成重叠子问题、并且子问题的最优解能拼出原问题的最优解，就可以用 DP。

入门阶段先不要背"状态转移方程"这种术语，按四个问题走一遍：

1. **状态是什么**：`dp[i][j]` 里的 `i`、`j` 各代表什么？
2. **怎么来的**：`dp[i][j]` 由哪些更小的状态推出来？
3. **初始值是什么**：最小的那些状态填什么？
4. **答案在哪儿**：最后输出哪个格子？

这四问想清楚，代码基本是照着填表。

必须养成的三个习惯：

- **先写递归再改递推**：能写出"暴力递归"，就能看出哪里重复计算，再把它改成填表，比硬想方程容易。
- **表开大一圈**：`dp[n][W]` 从 1 开始用，`dp[0][*]` 当初始值，能省掉大量边界判断。
- **填表顺序保证依赖已算好**：一维背包倒着推、区间 DP 按长度推、树形 DP 后序推，顺序错了结果就是错的，而且不报错。

本章共 6 道题：2 道精讲例题 + 4 道自选练习。

## 精讲例题

### 例题 1 · 数字三角形

给一个 n 层的数字三角形，从顶端出发，每次可以走到下一层的左边或右边，求到底部的最大路径和。

**输入**：第一行 n（≤ 100），随后 n 行，第 i 行有 i 个数。  
**输出**：最大路径和。

**样例**

输入：
```text
5
7
3 8
8 1 0
2 7 4 4
4 5 2 6 5
```
输出：
```text
30
```

**思路**：如果从上往下算，每个位置可能来自左上方或右上方，看着要分情况。反过来从下往上，每个位置只有"左下"和"右下"两个来源，一下就对称了。

状态定义：`dp[i][j]` 表示"从 `(i,j)` 走到底部的最大和"。转移就是 `dp[i][j] = a[i][j] + max(dp[i+1][j], dp[i+1][j+1])`。最底下一行直接等于自己。

从下往上填，最后 `dp[1][1]` 就是答案。这种"逆向定义状态"的技巧在 DP 里很常见，能省掉一半的边界讨论。

```c
/* 【应用】数字三角形：从下往上的线性 DP */
#include <stdio.h>

int a[105][105], dp[105][105];

int main(void)
{
    int n, i, j;

    scanf("%d", &n);
    for (i = 1; i <= n; ++i)
        for (j = 1; j <= i; ++j) scanf("%d", &a[i][j]);

    for (i = n; i >= 1; --i)
        for (j = 1; j <= i; ++j) {
            int best = dp[i + 1][j] > dp[i + 1][j + 1] ? dp[i + 1][j] : dp[i + 1][j + 1];
            dp[i][j] = a[i][j] + best;
        }

    printf("%d\n", dp[1][1]);
    return 0;
}
```

### 例题 2 · 0-1 背包

有 n 件物品，第 i 件重 `w[i]`、价值 `v[i]`，背包容量 W。每件物品只能取或不取，求能装下的最大总价值。

**输入**：第一行 n W（n ≤ 1000，W ≤ 1000），随后 n 行每行 w v。  
**输出**：最大总价值。

**样例**

输入：
```text
4 5
1 2
2 4
3 4
4 5
```
输出：
```text
8
```

**思路**：这是 DP 的招牌题，状态是"前 i 件物品、容量 j 时的最大价值"。

对第 i 件物品，只有两个选择：不拿，价值等于 `dp[i-1][j]`；拿，价值等于 `dp[i-1][j-w[i]] + v[i]`。两者取大。第二项必须检查 `j >= w[i]`，否则下标越界。

初始值 `dp[0][*] = 0`，因为一件都不拿价值为 0。答案是 `dp[n][W]`。

二维写法直观，适合入门。等熟了可以压成一维，但要记住**容量必须倒着循环**，否则一件物品会被拿多次，变成完全背包。

```c
/* 140【应用】0-1 背包：二维写法 */
#include <stdio.h>

int w[1005], v[1005];
int dp[1005][1005];

int main(void)
{
    int n, W, i, j;

    scanf("%d%d", &n, &W);
    for (i = 1; i <= n; ++i) scanf("%d%d", &w[i], &v[i]);

    for (i = 1; i <= n; ++i)
        for (j = 0; j <= W; ++j) {
            dp[i][j] = dp[i - 1][j];                 /* 不拿 */
            if (j >= w[i] && dp[i - 1][j - w[i]] + v[i] > dp[i][j])
                dp[i][j] = dp[i - 1][j - w[i]] + v[i];
        }

    printf("%d\n", dp[n][W]);
    return 0;
}
```

## 自选练习

::: details 练习 1 · 最长上升子序列（LIS）（题面与样例）

给 n 个整数，求最长严格上升子序列的长度（子序列不要求连续）。

**输入**：第一行 n（≤ 10³），第二行 n 个整数。  
**输出**：最长长度。

**样例**

输入：
```text
8
10 9 2 5 3 7 101 18
```
输出：
```text
4
```

`f[i]` 表示"以 a[i] 结尾的最长上升子序列长度"。转移是往前找所有比 a[i] 小的 a[j]，取最大的 `f[j] + 1`。答案是所有 `f[i]` 的最大值，不是 `f[n]`。

O(n²) 写法对 n ≤ 1000 够用。n 到 10⁵ 要换成"贪心 + 二分"，那是进阶内容。

:::

::: details 练习 1 · 参考代码

```c
/* 141【应用】最长上升子序列 O(n²) */
#include <stdio.h>

int a[100005], f[100005];

int main(void)
{
    int n, i, j, best = 0;

    scanf("%d", &n);
    for (i = 1; i <= n; ++i) scanf("%d", &a[i]);

    for (i = 1; i <= n; ++i) {
        f[i] = 1;
        for (j = 1; j < i; ++j)
            if (a[j] < a[i] && f[j] + 1 > f[i]) f[i] = f[j] + 1;
        if (f[i] > best) best = f[i];
    }

    printf("%d\n", best);
    return 0;
}
```

:::

::: details 练习 2 · 最长公共子序列（LCS）（题面与样例）

给两个字符串，求最长公共子序列的长度（不要求连续）。

**输入**：两行字符串，长度 ≤ 1000。  
**输出**：长度。

**样例**

输入：
```text
ABCBDAB
BDCABA
```
输出：
```text
4
```

`dp[i][j]` 表示"第一个串前 i 个字符、第二个串前 j 个字符的 LCS 长度"。

如果 `s[i] == t[j]`，这个字符一定可以配对，`dp[i][j] = dp[i-1][j-1] + 1`；否则至少有一个字符用不上，取 `max(dp[i-1][j], dp[i][j-1])`。

为了下标从 1 开始，用 `scanf("%s", s + 1)` 直接把输入存到 `s[1]` 起。

:::

::: details 练习 2 · 参考代码

```c
/* 【应用】最长公共子序列 */
#include <stdio.h>
#include <string.h>

char s[1005], t[1005];
int dp[1005][1005];

int main(void)
{
    int n, m, i, j;

    scanf("%s", s + 1);
    scanf("%s", t + 1);
    n = (int)strlen(s + 1);
    m = (int)strlen(t + 1);

    for (i = 1; i <= n; ++i)
        for (j = 1; j <= m; ++j) {
            if (s[i] == t[j]) dp[i][j] = dp[i - 1][j - 1] + 1;
            else dp[i][j] = dp[i - 1][j] > dp[i][j - 1] ? dp[i - 1][j] : dp[i][j - 1];
        }

    printf("%d\n", dp[n][m]);
    return 0;
}
```

::: details 练习 3 · 石子合并（区间 DP）（题面与样例）

n 堆石子排成一排，每次只能合并相邻两堆，代价是两堆石子数之和。求合并成一堆的最小总代价。

**输入**：第一行 n（≤ 200），第二行 n 个整数。  
**输出**：最小总代价。

**样例**

输入：
```text
4
1 3 5 2
```
输出：
```text
22
```

`f[i][j]` 表示把第 i 到第 j 堆合并成一堆的最小代价。最后一次合并一定是把 `[i,k]` 和 `[k+1,j]` 两堆并起来，代价是这段的总和，所以：

`f[i][j] = min{ f[i][k] + f[k+1][j] } + sum(i..j)`

**填表顺序必须是按区间长度从小到大**，因为长区间的值依赖短区间。写成 `for (len = 2; len <= n; ++len)` 是最不容易错的方式。区间和用前缀和 O(1) 取。

:::

::: details 练习 3 · 参考代码

```c
/* 142【应用】区间 DP：石子合并 */
#include <stdio.h>

#define INF 1000000000

int a[205], sum[205];
int f[205][205];

int main(void)
{
    int n, i, j, k, len;

    scanf("%d", &n);
    for (i = 1; i <= n; ++i) {
        scanf("%d", &a[i]);
        sum[i] = sum[i - 1] + a[i];
    }

    for (len = 2; len <= n; ++len)
        for (i = 1; i + len - 1 <= n; ++i) {
            j = i + len - 1;
            f[i][j] = INF;
            for (k = i; k < j; ++k) {
                int c = f[i][k] + f[k + 1][j] + sum[j] - sum[i - 1];
                if (c < f[i][j]) f[i][j] = c;
            }
        }

    printf("%d\n", f[1][n]);
    return 0;
}
```

::: details 练习 4 · 换零钱的方案数（完全背包）（题面与样例）

给 n 种面额的硬币（每种无限多）和一个金额 m，求凑出 m 的方案数，顺序不同算同一种。

**输入**：第一行 n m（n ≤ 100，m ≤ 10⁴），第二行 n 个面额。  
**输出**：方案数。

**样例**

输入：
```text
3 5
1 2 5
```
输出：
```text
4
```

`f[j]` 表示凑出金额 j 的方案数，`f[0] = 1`（什么都不取的方案算一种）。

外层枚举硬币、内层**正着**枚举金额，就是完全背包：一件物品可以被重复使用。如果内层倒着来，就变成每种硬币只能用一次的 0-1 背包。

顺序不同算同一种，靠的正是"外层硬币、内层金额"这个循环顺序：每个方案只会在最小的那个硬币被处理时生成一次。

:::

::: details 练习 4 · 参考代码

```c
/* 【应用】完全背包：凑零钱方案数 */
#include <stdio.h>

int c[105];
long long f[10005];

int main(void)
{
    int n, m, i, j;

    scanf("%d%d", &n, &m);
    for (i = 0; i < n; ++i) scanf("%d", &c[i]);

    f[0] = 1;
    for (i = 0; i < n; ++i)
        for (j = c[i]; j <= m; ++j)
            f[j] += f[j - c[i]];

    printf("%lld\n", f[m]);
    return 0;
}
```

## 本章小结

DP 的四个步骤：**定状态、写转移、填初值、找答案**。所有入门题的差别只在这四步的具体内容上。

三个容易踩的坑：状态定义重复计算（该用 `max` 的地方写成求和）、填表顺序错（长区间先算）、边界没处理（`j - w[i]` 越界）。写完之后拿样例和自己的暴力递归对一遍，是发现这些问题最快的方式。
