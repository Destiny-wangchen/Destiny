# C 语言例题册

一份按**知识点**组织、讲练分离的 C 语言入门题册。每一章先讲清楚一类知识点，再带 2 道精讲例题，其余题目放进折叠块——读完知识点后，你可以自己先写，再展开对照参考代码。

- 共 8 章 **75 道题**，全部题目配有可运行的参考代码
- 题目经过改写，去掉了课程背景，任何 C 语言初学者都可以直接练
- 推荐配合本地编译器（Dev-C++ / gcc）使用：写完拿样例测一测，再对答案

## 建议的使用方式

1. 先读本章「知识点」部分，把格式控制、常见坑过一遍；
2. 精讲例题建议**先遮住代码**，只看题面自己写，再看讲解与代码；
3. 自选练习按需选做，折叠块里的样例可以直接拿来当本地测试数据；
4. 卡住了再展开参考代码——对照差距比直接看答案收获大得多。
