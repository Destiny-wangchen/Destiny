前九章写的是"把题做出来"，从这一章开始要写"让题跑得动"。区别很具体：数据量从 n ≤ 100 变成 n ≤ 10⁵，两层循环从"慢一点"变成"超时"。

这一章的四样东西，都是同一个思路的不同变体：**用一次预处理，换掉后面每一次的重复计算**。

- **前缀和**：预处理一次，之后每次区间求和 O(1)。
- **差分**：预处理一次，之后每次区间修改 O(1)。
- **双指针**：两个下标同向移动，总移动次数 O(n)，把"枚举所有区间"变成"扫一遍"。
- **二分**：靠单调性把候选范围每次砍一半，O(log n)；二分答案更进一步，把"求最优值"变成"判断可行性"。

必须养成的三个习惯：

- **先看数据范围再写代码**：n ≤ 100 随便写，n ≤ 10⁵ 就要 O(n log n)；n ≤ 10⁶ 基本只能 O(n)。
- **下标从 1 开始**：前缀和、差分的公式都带 `i-1`，从 1 开始能省掉一堆边界判断。
- **求和用 `long long`**：10⁵ 个 10⁵ 量级的数加起来是 10¹⁰，`int` 装不下。这是第 02 例讲过的内容。

本章共 7 道题：2 道精讲例题 + 5 道自选练习。

## 精讲例题

### 例题 1 · 区间求和（前缀和）

给一个长度为 n 的数组，回答 q 次询问，每次问区间 `[l, r]` 的元素和。

**输入**：第一行 n q（n ≤ 10⁵，q ≤ 10⁵），第二行 n 个整数，随后 q 行每行 l r。  
**输出**：每次询问一行答案。

**样例**

输入：
```text
5 3
1 2 3 4 5
1 3
2 5
4 4
```
输出：
```text
6
14
4
```

**思路**：每次询问都从头累加是 O(nq)，10¹⁰ 次操作，必然超时。

预先算一个前缀和数组 `pre[i] = a[1] + a[2] + ... + a[i]`，那么 `a[l] + ... + a[r] = pre[r] - pre[l-1]`。一次 O(n) 预处理，以后每次询问 O(1)。

`pre[0] = 0` 这一项别省，`l = 1` 时 `pre[0]` 正好用上，省掉一个 `if`。

```c
/* 121【应用】前缀和：区间求和 O(1) */
#include <stdio.h>

int main(void)
{
    int n, q, i, l, r, a[100005];
    long long pre[100005];

    scanf("%d%d", &n, &q);
    pre[0] = 0;
    for (i = 1; i <= n; ++i) {
        scanf("%d", &a[i]);
        pre[i] = pre[i - 1] + a[i];
    }

    while (q--) {
        scanf("%d%d", &l, &r);
        printf("%lld\n", pre[r] - pre[l - 1]);
    }
    return 0;
}
```

> 用 Dev-C++ 自带的 gcc 4.9 编译时，`-Wall` 可能对 `%lld` 报 `unknown conversion type character 'l'`。这是它的格式检查器默认按 MSVCRT 规则判断导致的误报，运行结果是对的。想让警告消失，在编译选项里加 `-D__USE_MINGW_ANSI_STDIO=1`。

### 例题 2 · 切木头（二分答案）

有 n 根木头，长度分别为 `l[i]`。要从里面切出 k 段长度相同的木头，求最大可能的段长（取整）。

**输入**：第一行 n k（n ≤ 10⁵），第二行 n 个长度（≤ 10⁹）。  
**输出**：最大段长。

**样例**

输入：
```text
4 11
802 743 457 539
```
输出：
```text
200
```

**思路**：直接枚举段长要试到 10⁹，太慢。

换个角度：如果段长是 L，能切出多少段？答案是 `Σ(l[i] / L)`，这个函数随 L 增大而单调减少。题目就是要求"满足 f(L) ≥ k 的最大 L"，典型的单调判定，可以二分。

二分的框架记四句话：**定下界、定上界、写判定、选收缩方向**。这里上界取最长的那根木头，判定是段数总和，段数够 k 就往右找（更大的 L），不够就往左找。

`mid` 用 `int` 够用，但 `cnt` 必须 `long long`：10⁵ 根木头，每根切出 10⁹ 段的话会溢出。

```c
/* 126【应用】二分答案：切木头 */
#include <stdio.h>

int main(void)
{
    int n, k, i, l[100005], lo = 1, hi = 0, ans = 0;

    scanf("%d%d", &n, &k);
    for (i = 0; i < n; ++i) {
        scanf("%d", &l[i]);
        if (l[i] > hi) hi = l[i];
    }

    while (lo <= hi) {
        int mid = (lo + hi) / 2;
        long long cnt = 0;
        for (i = 0; i < n; ++i) cnt += l[i] / mid;
        if (cnt >= k) { ans = mid; lo = mid + 1; }
        else hi = mid - 1;
    }

    printf("%d\n", ans);
    return 0;
}
```

## 自选练习

::: details 练习 1 · 区间加（差分）（题面与样例）

给长度为 n 的数组，做 m 次操作，每次把区间 `[l, r]` 内所有元素加 v。输出最终数组。

**输入**：第一行 n m，第二行 n 个整数，随后 m 行每行 l r v。  
**输出**：最终数组一行，空格分隔。

**样例**

输入：
```text
5 2
0 0 0 0 0
1 3 2
2 5 1
```
输出：
```text
2 3 3 1 1
```

差分数组的定义是 `d[i] = a[i] - a[i-1]`。对 `[l, r]` 整体加 v，在差分里只改两处：`d[l] += v`，`d[r+1] -= v`。最后做一遍前缀和就还原成原数组。

一次区间修改从 O(n) 降到 O(1)，m 次操作 O(m)，加最后一遍 O(n)，比暴力快一个量级。

:::

::: details 练习 1 · 参考代码

```c
/* 122【应用】差分：区间加 + 最后还原 */
#include <stdio.h>

int main(void)
{
    int n, m, i, l, r, v, a[100005];
    long long d[100005];

    scanf("%d%d", &n, &m);
    for (i = 1; i <= n; ++i) { scanf("%d", &a[i]); d[i] = 0; }

    while (m--) {
        scanf("%d%d%d", &l, &r, &v);
        d[l] += v;
        d[r + 1] -= v;
    }

    long long cur = 0;
    for (i = 1; i <= n; ++i) {
        cur += d[i];
        a[i] += (int)cur;
        printf("%d%c", a[i], i == n ? '\n' : ' ');
    }
    return 0;
}
```

::: details 练习 2 · 最短的达标区间（双指针）（题面与样例）

给 n 个**正整数**和一个目标 s，求和 ≥ s 的最短连续子数组长度；不存在输出 0。

**输入**：第一行 n s（n ≤ 10⁵），第二行 n 个正整数。  
**输出**：最短长度或 0。

**样例**

输入：
```text
10 15
5 1 3 5 10 7 4 9 2 8
```
输出：
```text
2
```

两个指针 `l`、`r`，`r` 一路往右加，`sum` 够了就尝试把 `l` 往右挪，同时更新最短长度。因为每个元素最多被加一次、减一次，总复杂度 O(n)。

注意 `while (sum - a[l] >= s)` 这个条件：它表示"挪掉 a[l] 之后仍然达标"，所以可以安全地挪。正整数的前提不能丢，有负数就不单调了。

:::

::: details 练习 2 · 参考代码

```c
/* 124【应用】双指针（滑动窗口）求最短达标区间 */
#include <stdio.h>

int main(void)
{
    int n, s, i, l = 0, best = 0, a[100005];
    long long sum = 0;

    scanf("%d%d", &n, &s);
    for (i = 0; i < n; ++i) scanf("%d", &a[i]);

    for (i = 0; i < n; ++i) {
        sum += a[i];
        while (sum - a[l] >= s) { sum -= a[l]; ++l; }
        if (sum >= s) {
            int len = i - l + 1;
            if (best == 0 || len < best) best = len;
        }
    }

    printf("%d\n", best);
    return 0;
}
```

::: details 练习 3 · 第一个不小于 x 的位置（二分查找）（题面与样例）

给一个升序数组，回答 q 次询问：第一个 ≥ x 的元素下标（1 起）；不存在输出 `-1`。

**输入**：第一行 n q，第二行 n 个升序整数，随后 q 行每行一个 x。  
**输出**：每次询问一行。

**样例**

输入：
```text
5 3
1 3 5 7 9
4
5
10
```
输出：
```text
3
3
-1
```

二分找一个"边界"时，用 `ans` 记住当前可行解，再决定往哪半边收缩，比写两套模板更不容易错。条件是 `a[mid] >= x` 就往左收缩并记下 `mid`，否则往右。

:::

::: details 练习 3 · 参考代码

```c
/* 125【应用】二分查找：第一个 >= x 的位置 */
#include <stdio.h>

int main(void)
{
    int n, q, i, x, a[100005];

    scanf("%d%d", &n, &q);
    for (i = 1; i <= n; ++i) scanf("%d", &a[i]);

    while (q--) {
        scanf("%d", &x);
        int lo = 1, hi = n, ans = -1;
        while (lo <= hi) {
            int mid = (lo + hi) / 2;
            if (a[mid] >= x) { ans = mid; hi = mid - 1; }
            else lo = mid + 1;
        }
        printf("%d\n", ans);
    }
    return 0;
}
```

::: details 练习 4 · 最多能参加几场活动（贪心）（题面与样例）

给 n 个时间区间 `[s, e]`，一个人同一时间只能参加一场，求最多能参加几场。前一场结束时间 ≤ 后一场开始时间即可接上。

**输入**：第一行 n，随后 n 行每行 s e。  
**输出**：最多场次。

**样例**

输入：
```text
4
1 3
2 4
3 5
5 6
```
输出：
```text
3
```

贪心策略是**按结束时间排序**，能接就接。为什么不是按开始时间？按开始时间会先选一个很早开始但很晚结束的区间，把后面全挡住；按结束时间选，每次都给后面留最大的余地。

这个"交换论证"值得自己想一遍：任何最优解的第一场，都能换成结束最早的那一场而不变差。

:::

::: details 练习 4 · 参考代码

```c
/* 127【应用】区间调度：按结束时间贪心 */
#include <stdio.h>
#include <stdlib.h>

typedef struct { int s, e; } Seg;

int cmp(const void *x, const void *y)
{
    const Seg *a = (const Seg *)x, *b = (const Seg *)y;
    if (a->e != b->e) return a->e - b->e;
    return a->s - b->s;
}

int main(void)
{
    Seg seg[100005];
    int n, i, cnt = 0, last = -1;

    scanf("%d", &n);
    for (i = 0; i < n; ++i) scanf("%d%d", &seg[i].s, &seg[i].e);

    qsort(seg, n, sizeof(Seg), cmp);

    for (i = 0; i < n; ++i)
        if (seg[i].s >= last) { ++cnt; last = seg[i].e; }

    printf("%d\n", cnt);
    return 0;
}
```

::: details 练习 5 · 子矩阵求和（二维前缀和）（题面与样例）

给一个 n×m 的矩阵，回答 q 次询问，每次问左上角 `(x1,y1)` 到右下角 `(x2,y2)` 的子矩阵元素和。

**输入**：第一行 n m q，随后 n 行每行 m 个整数，再随后 q 行每行 x1 y1 x2 y2。  
**输出**：每次询问一行。

**样例**

输入：
```text
2 3 2
1 2 3
4 5 6
1 1 2 2
1 2 1 3
```
输出：
```text
12
5
```

二维前缀和是容斥原理：`s[i][j] = a[i][j] + s[i-1][j] + s[i][j-1] - s[i-1][j-1]`，查询时 `s[x2][y2] - s[x1-1][y2] - s[x2][y1-1] + s[x1-1][y1-1]`。

四个角里减了两次的 `s[x1-1][y1-1]` 要加回来。这四行公式建议手推一遍再抄，抄错的概率很高。

:::

::: details 练习 5 · 参考代码

```c
/* 128【应用】二维前缀和 */
#include <stdio.h>

int a[1005][1005];
long long s[1005][1005];

int main(void)
{
    int n, m, q, i, j, x1, y1, x2, y2;

    scanf("%d%d%d", &n, &m, &q);
    for (i = 1; i <= n; ++i)
        for (j = 1; j <= m; ++j) {
            scanf("%d", &a[i][j]);
            s[i][j] = a[i][j] + s[i - 1][j] + s[i][j - 1] - s[i - 1][j - 1];
        }

    while (q--) {
        scanf("%d%d%d%d", &x1, &y1, &x2, &y2);
        printf("%lld\n",
               s[x2][y2] - s[x1 - 1][y2] - s[x2][y1 - 1] + s[x1 - 1][y1 - 1]);
    }
    return 0;
}
```

## 本章小结

四板斧的共同点：**把重复计算提前做掉**。前缀和提前算"从 1 到 i 的和"，差分提前记"变化量"，双指针靠单调性避免回退，二分靠单调性一次砍一半。

判断该用哪个，看两件事：数据量有多大、有没有单调性。这两条想清楚了，代码基本是套模板。
