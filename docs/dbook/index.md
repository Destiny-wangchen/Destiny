这门课最难受的地方不是难，而是**没人能替你想象**。老师讲得再清楚，最后还是要你自己在脑子里把那个立体转过来；答案看一眼就懂，合上又不会。

这份例题册把「工图 C」的考点拆成七章，每章只讲一件事，配的图全部是**按投影规律重新画的矢量图**——放大不失真，虚线、点划线、剖面线都按国标来，可以对着屏幕一根线一根线地核对。

- 共 7 章，从三视图的形成一路讲到尺寸标注
- 图上的字母标注沿用国标习惯：`a` 水平投影、`a′` 正面投影、`a″` 侧面投影
- 每章末尾有「自查清单」，做完题对一遍，能挡住大部分冤枉分

## 建议的用法


1. 先看第 1 章，把考试结构、线型规范弄清楚，这决定你后面画图的手感；
2. 每一章先读「怎么想」，再看图，最后自己**拿纸笔照着题意画一遍**——这门课看会不等于会画；
3. 卡住时不要急着看答案，先把图上的点标出来（`1、2、3、4`），很多时候标完点线就出来了；
4. 全部学完后，用真题卷限时做一遍，重点检查虚线有没有漏、被截去的轮廓有没有擦掉。
