# 第 1 章 · 沙子的魔法：半导体与晶体管

芯片的原材料便宜得离谱——沙子。海滩上最常见的二氧化硅，提纯后就是硅。但一块硅怎么就变成了能跑 AI 大模型的芯片？这一章讲清楚三件事：**硅凭什么、晶体管怎么开关、摩尔定律把这一切推到了什么程度**。

## 1.1 半导体：能被驯服的"半吊子导体"

金属里挤满了自由电子，一通电就全跑起来；橡胶里的电子被牢牢锁住，怎么都不动。硅正好卡在中间：它平时导电能力很差，但有一个神奇的性质——**掺入不同的杂质，就能精确控制它导电多少**。

往硅里掺一点硼，导电靠"空穴"，叫 **P 型**；掺一点磷或砷，导电靠电子，叫 **N 型**。把 P 型和 N 型贴在一起，交界处形成一个 **PN 结**——电流只能单向通过。这就是二极管，所有半导体器件的基石。

> **重点**：半导体的"半"不是缺点，而是可编程性。金属和绝缘体出厂时就定了性，半导体却可以被人工"调教"，这才有后面的一切故事。

## 1.2 晶体管：用电压控制的水龙头

晶体管本质上是一个**用电信号控制的开关**。最常用的类型叫 MOSFET（金属-氧化物-半导体场效应晶体管），三个端子：

- **源（Source）和漏（Drain）**：电流进出的通道，中间隔着一小段硅；
- **栅（Gate）**：悬在通道上方，中间隔一层薄薄的绝缘层（二氧化硅），不直接接触。

给栅极加电压，它的电场会"隔着绝缘层"把通道里的载流子拉过来或推开——通道导通或关断。就像水龙头：栅极是把手，拧一下，水（电流）就通或断。

计算机里所有的 0 和 1，就是靠亿万个这样的开关组合出来的。开关状态的切换靠的是电场，几乎不消耗电流，所以晶体管又小又省电——这正是它取代真空管的理由。

## 1.3 晶体管结构演进：栅极越包越紧

晶体管变小会遇到一个麻烦：沟道短了以后，栅极"隔空控制"的能力变弱，电流会在不该通的时候漏过去（漏电）。整个先进工艺的演进史，就是一部**给栅极加包裹**的历史：

```
平面 MOSFET（一面控制）→ FinFET（三面包裹，22nm 起）→ GAA 环栅（四面包裹，3nm/2nm）
```

平面时代栅极只能从上方按住沟道；FinFET 把沟道立起来变成鱼鳍，栅极三面环抱；GAA（Gate-All-Around）干脆让栅极把沟道整个圈住，控制力最强、漏电最小。**记住一个逻辑：尺寸缩小 → 栅控变弱 → 换更强的包裹方式**，考试和面试里这条线反复出现。

## 1.4 摩尔定律：指数爆炸的六十年

1965 年，英特尔的戈登·摩尔注意到：**芯片上的晶体管数量大约每两年翻一倍**。这不是物理定律，而是一个产业预期——但全行业按它排节奏，居然真的跑了六十年。

看一组数字：

| | Intel 4004（1971） | Core i7（2011） |
|---|---|---|
| 晶体管数 | 2300 | 约 11.7 亿 |
| 工艺 | 10 微米 | 32 纳米 |
| 时钟 | 108 kHz | 3.2 GHz |

40 年，晶体管数提升约 50 万倍。而 4004 的算力据称相当于 1946 年的 ENIAC——那台机器重 27 吨、占地 167 平方米。今天的手机算力又比 2011 年的桌面 CPU 高几个数量级。同时，单个晶体管的价格一路狂跌，**性能越来越强、价格越来越便宜**，这就是信息革命的物质基础。

摩尔定律如今明显放缓，但还在靠三条腿走路：更先进的光刻和工艺节点、Chiplet 拆分大芯片、以及换赛道（详见第 7 章）。

## 1.5 一段历史：三级跳

| 年份 | 事件 | 意义 |
|------|------|------|
| 1947 | 点接触晶体管（贝尔实验室） | 取代真空管：小、省电、可靠 |
| 1958 | Jack Kilby 做出第一块混合 IC（锗） | 把多个器件连在一块材料上 |
| 1959 | Noyce 的单片 IC（硅，平面工艺） | 现代芯片的雏形：所有器件"画"在同一块硅上 |
| 1965 | 摩尔定律提出 | 给全行业一个加速度 |
| 1971 | Intel 4004 | 第一款商用微处理器 |

注意区分：Kilby 的 IC 是锗做的**混合 IC**（器件间用导线连接），Noyce 才是硅基**单片 IC**（全部集成在一片半导体里）——这道辨析题考过无数次。

## 1.6 CMOS：为什么它能一统天下

CMOS = Complementary MOS，互补 MOS。思路是成对使用 NMOS 和 PMOS：一个管"0"时导通，另一个管"1"时导通，**永远有一个截止**。截止的管子几乎没有电流通过，所以 CMOS 电路在静态时功耗接近零——只有开关瞬间消耗一点动态功耗。

低功耗意味着可以把几十亿个晶体管塞进一颗芯片而不把电烧干。没有 CMOS，就没有智能手机。顺带说：手机摄像头常说的"CMOS 传感器"，就是用这套电路技术读出感光像素的信号——CMOS 是母概念，图像传感器只是它最成功的应用之一。

## 本章记住三句话

1. 硅的导电性可以用掺杂精确控制，PN 结让电流单向通过——这是所有器件的基石。
2. 晶体管是电压控制的开关；结构演进（平面→FinFET→GAA）就是为了在尺寸缩小时加强栅控、抑制漏电。
3. CMOS 用互补结构实现静态近零功耗，是摩尔定律能持续六十年的电路基础。
