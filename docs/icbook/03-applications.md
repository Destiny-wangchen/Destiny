# 第 3 章 · 芯片藏在哪：手机、汽车与 AI

前两章讲了晶体管和制造，这一章看应用：任何电子系统都能拆成**感知—处理—执行—供电—通信**五大部分，芯片就是在这些环节里各就各位。拆一台手机，你就能看清芯片世界的全貌。

## 3.1 拆一台手机

| 功能 | 芯片 | 干什么 |
|------|------|--------|
| 思考 | SoC | CPU、GPU、NPU 等十几种子系统集成在一颗芯片上 |
| 记忆 | LPDDR + UFS | 运行内存 + 闪存 |
| 感知 | CIS + MEMS 传感器 | 摄像头、加速度计、陀螺仪、指纹、环境光……十几个 |
| 供能 | PMU / DC-DC / LDO | 电源管理——省电的艺术 |
| 通信 | 基带 + 射频 + Wi-Fi/BT/NFC | 与外界对话 |
| 连接 | USB / HDMI 接口芯片 | 与外设对话 |

"思考"那颗 SoC 里到底有什么？CPU 集群（ARM Cortex）、GPU、DSP（信号处理）、ISP（图像处理）、NPU（AI 加速）、各类控制器和电源管理。设计思想一句话：**能集成就不外挂**——省面积、省功耗、降成本。

## 3.2 信号链：模拟世界与数字世界的桥

真实世界的声音、光、温度都是**连续的模拟量**，计算机只认 0 和 1。中间必须有个翻译过程，这就是**信号链**：

```
传感器 → 放大滤波（模拟前端）→ ADC → 数字处理/存储 → DAC → 驱动 → 执行器
```

ADC（模数转换器）和 DAC（数模转换器）是"翻译官"，属于混合信号芯片。理解信号链，你就理解了为什么传感器厂商（第 4、5 章）和处理器厂商最终都会走到同一张桌上——完整产品必须把链路打通。

## 3.3 PPA：芯片设计的不可能三角

芯片设计的核心指标叫 **PPA**：

- **Performance** 性能：跑得快；
- **Power** 功耗：省电；
- **Area** 面积：小（面积直接等于成本）。

三者互相牵制，芯片设计本质是折中艺术。消费电子把功耗和成本放在第一位（一年一代、价格敏感）；工业电子把可靠性放在第一位——宽温、抗振动、长寿命，芯片不一定先进，但一定要稳。

## 3.4 电源管理：每一毫安时都要花在刀刃上

手机电池就这么大，省电靠三板斧：

- **DVFS**（动态电压频率调节）：负载轻时降频降压，闲时小步慢跑；
- **时钟门控 / 电源门控**：暂时不用的模块直接停时钟甚至断电；
- **休眠唤醒**：绝大多数时间芯片在浅睡，事件来了再秒醒。

功率类芯片（DC-DC、LDO、PMU）因此成为手机里除 SoC 外最重要的一族——算力再强，没电一切归零。

## 3.5 汽车电子：从"多个小脑"到"一个大脑"

汽车电子架构正在经历一场集权改革：

```
分布式 ECU（每个功能一个盒子，线束爆炸）
  → 域集中 DCU（按动力/底盘/座舱/驾驶分域）
    → 中央计算 VCU（一个大脑 + 区域控制器）
```

智能驾驶靠**传感器融合**：摄像头管视觉、毫米波雷达管测距测速、激光雷达管高精度 3D、超声波管近距、GNSS 管定位——数据汇到 AI 平台做决策。汽车芯片的硬约束不是"算力拉满"，而是**实时性（确定性延迟）+ 功能安全（ASIL 等级认证）**：刹车延迟几十毫秒就是事故。

## 3.6 AI 算力与架构光谱

大模型的参数从亿级涨到万亿级，算力需求指数增长。但手机、汽车、安防不可能都插着电——芯片设计的核心矛盾变成：**在有限功耗下榨出最多算力**。不同的架构在这个问题上站在光谱的不同位置：

| 架构 | 能效 | 灵活性 | 定位 |
|------|------|--------|------|
| ASIC | 最高 | 最低 | 全定制，量产摊薄成本（NPU 硬化） |
| DSA | 高 | 低 | 领域专用架构 |
| FPGA / CGRA | 中 | 高 | 可重构，原型验证、小批量 |
| GPU | 中低 | 高 | 并行通用计算 |
| CPU | 最低 | 最高 | 通用逻辑控制 |

越专用越高效、越通用越灵活，这是永恒的权衡。提升算力还有四条路：**高速高密度互连、创新架构（存算一体等）、先进工艺、Chiplet**。

- **存算一体**：AI 计算中"搬运数据"消耗的能量远大于计算本身，那就干脆把计算做进存储器里，消灭搬运。
- **Chiplet（芯粒）**：把大芯片拆成多个小芯片，各自用最合适的工艺制造，再像拼乐高一样封装在一起。小芯片良率高、成本低，还能异构混搭——大芯片时代的主流路线。

## 3.7 一个案例：特斯拉 FSD 芯片

看一个把本章概念全用上的实例。特斯拉 FSD 自动驾驶芯片：6 亿晶体管、14nm FinFET 工艺、ARM A72 CPU + Mali GPU + ISP + **双 NPU**（各 36 TOPS，合计 72 TOPS）+ 32MB SRAM。它体现了自动驾驶芯片的设计范式：**高算力 + 多核异构 + 安全冗余**——CPU 管逻辑、GPU 管通用并行、NPU 专攻神经网络，各司其职。

## 本章记住三句话

1. 任何电子系统 = 感知—处理—执行—供电—通信；信号链是模拟与数字世界之间的翻译过程。
2. PPA（性能/功耗/面积）是不可能三角；消费电子卷成本功耗，工业汽车电子卷可靠性和实时安全。
3. 架构光谱：越专用能效越高（ASIC），越通用灵活性越强（CPU）；算力突破靠新架构、先进工艺和 Chiplet。
