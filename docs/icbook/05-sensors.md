人和机器的对应关系一句话就够：**人靠五感获取信息、大脑处理、四肢执行；机器靠传感器感知、计算机处理、执行器动作**。传感器、通信、计算机并称信息技术三大支柱——而传感器发展最慢，所以也是瓶颈。这一章讲传感器的通用框架和各种原理。

## 5.1 传感器的三件套

所有传感器都可以拆成三部分（背下来，考试和设计都从它出发）：

1. **敏感元件**：直接感受被测量。比如压力传感器的膜片，感受到压力就变形；
2. **转换元件**：把"感受"变成电路参数的变化——电阻、电容、电感、电荷；
3. **转换电路**：把电路参数变成电压/电流输出。

三种形态：

- **简单型**：只有敏感元件，直接输出电信号。热电偶是代表——两种金属接在一起，两端温度不同就产生电动势，天生自带"发电"能力；
- **标准型**：三件套齐全。应变片 + 电桥是代表；
- **复杂型**：要经过多次转换。生物传感器最典型：分子识别 → 化学变化 → 电信号。

读任何传感器资料都用这三个问题拆它：**输入是什么？中间变成什么？输出是什么？**

## 5.2 怎么评价一个传感器：静态特性六指标

把传感器放在"输入不变"的稳态下考核，有六个指标（公式里的 \(y_{F.S.}\) 是满量程输出）：

| 指标 | 公式 | 直觉理解 |
|------|------|---------|
| 线性度 | \(e_L = \pm\dfrac{\Delta L_{max}}{y_{F.S.}}\times100\%\) | 校准曲线偏离直线有多远 |
| 迟滞 | \(e_H = \dfrac{\Delta H_{max}}{y_{F.S.}}\times100\%\) | 加压和减压走出来的曲线不重合（像门轴有旷量） |
| 重复性 | \(e_R = \pm\dfrac{a\sigma_{max}}{y_{F.S.}}\times100\%\) | 同方向反复测，数据散不散 |
| 灵敏度 | \(K = \Delta y/\Delta x\) | 输入变一点，输出变多少 |
| 分辨率 | 最小可测输入变化 | 能察觉的最小变化量 |
| 阈值 | 零位附近的最小输入 | 多小的输入才开始有反应 |

传感器输入-输出关系写成 \(y = a_0 + a_1x + a_2x^2 + \cdots\)。理想情况只有 \(a_1\)（灵敏度 K），高次项就是非线性误差的来源。两个容易混的点：

- **分辨率 vs 阈值**：分辨率是任意工作点的最小可测变化，阈值特指零位附近；
- **迟滞 vs 重复性**：迟滞看正反行程差，重复性看同方向多次测量的分散——是完全不同的误差源。

动态响应方面，核心工具是传递函数、频率响应（伯德图）和阶跃响应；**截止频率**定义为幅值下降 3dB（降到 0.707）的位置——传感器能"跟得上"的信号速度上限。

## 5.3 各类传感器速查表

按转换原理分类，每类记一个核心公式和应用场景：

| 类型 | 核心公式 | 变换链 | 特点 |
|------|---------|--------|------|
| 电阻式（应变片） | \(R=\rho l/A\) | 力→形变→电阻 | 半导体式灵敏度高但温漂大 |
| 电感式 | L 随气隙变化 | 位移→磁阻→电感 | 常用差动结构 |
| 电涡流 | 涡流效应 | 位移→涡流→阻抗 | **非接触**，测位移/振动/厚度/转速 |
| 电容式 | \(C=\varepsilon_0\varepsilon_r A/\delta\) | 改变间距 δ / 面积 A / 介质 εr | 分辨率极高、功耗低，MEMS 主力 |
| 磁电式 | \(e=-W\,d\Phi/dt\)；\(e=Blv\) | 速度→感应电动势 | **有源**（自己发电），只能测动态 |
| 压电式 | 力→表面电荷 | 力→电荷 | 高频好、低频差（电荷会泄漏） |
| 热电阻 | 温度→电阻 | 铂/铜/镍 | 需恒流激励 |
| 热电偶 | 温差→热电动势 | 直接输出电压 | 简单型代表，工业测温主力 |
| 光电式 | \(E=h\nu\) | 光→电子逸出/电阻/电动势 | 分外光电和内光电 |
| 光纤式 | \(NA=\sqrt{n_1^2-n_2^2}\) | 光调制 | 抗电磁干扰，本征安全 |
| 湿敏 | \(HR=P_h/P_s\times100\%\) | 湿度→电阻/电容 | 电解质/陶瓷/聚合物材料 |
| 生物式 | 分子识别+换能 | 目标分子→电信号 | 专一、快速、准确 |

光电式再展开一点，考试爱考：

- **外光电效应**：光子能量 \(E=h\nu\) 大于逸出功，电子**飞出**物体表面——光电管、光电倍增管；
- **内光电效应**：电子不逸出，分两种——**光电导效应**（光改变电导率，光敏电阻）和**光生伏特效应**（光产生电动势，光电池、光电二极管）。

热敏电阻三种别记反：**NTC** 温度升电阻降、**PTC** 温度升电阻升、**CTR** 在临界温度电阻突变。

## 5.4 差动技术：提升性能的万能招

用一个对称结构把性能全面拉高：两个敏感单元，一个增一个减，**取差值输出**。效果：

1. 灵敏度**翻倍**（两个变量相加）；
2. 非线性误差减小（奇次项互相抵消）；
3. **共模干扰自动抵消**——温度等同时作用在两个单元上的因素，在差值里消失了。

自感式、电容式、应变片电桥全都爱用差动结构。看到"差动"二字，就想到"灵敏度×2、非线性减半、抗共模"这三件事。

## 5.5 校准：给传感器做体检

- **静态校准**：用标准量具逐点加载，测灵敏度、线性度、迟滞、重复性。拟合直线最常用的方法是**最小二乘法**（残差平方和最小）；
- **动态校准**：测固有频率、频响范围、动态灵敏度。标准激励两种：**正弦波**（周期信号）和**阶跃波**（瞬态信号）；
- 多维力传感器（如机器人六维腕力传感器）：从不同方向加载 → 记录输出 → 拟合标定矩阵。

## 5.6 智能化：传感器的进化方向

传统传感器只是"翻译官"，智能传感器芯片把敏感结构、转换电路、处理电路甚至通信接口集成到一颗芯片上（呼应第 3 章的手机传感器全家桶）。行业趋势五个词：**小型化、集成化、智能化、网络化、仿生化**。MEMS 工艺（第 4 章）是实现小型化和集成化的关键手段——这也是为什么传感器课程和 MEMS 课程总是连着上。

## 本章记住三句话

1. 传感器三件套：敏感元件 + 转换元件 + 转换电路；分析任何传感器都问"输入是什么、中间变成什么、输出是什么"。
2. 静态六指标（线性、迟滞、重复、灵敏、分辨、阈值），截止频率是 -3dB 点；磁电式只能测动态，压电式低频差。
3. 差动结构 = 灵敏度翻倍 + 非线性减半 + 共模干扰抵消，是提升传感器性能的万能招。
