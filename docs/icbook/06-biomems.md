BioMEMS = MEMS + 生物医学。把第 4 章的微加工技术用在两个方向：**体外**——芯片接触血液、唾液、细胞培养液做诊断分析（血糖仪、DNA 芯片、细胞分选）；**体内**——植入人体的神经植入物、耳蜗植入、智能药丸、可吸收支架。

它的价值一句话说清：**样本只要纳升级、结果几分钟出、一块芯片顶一间实验室**。

## 6.1 微流控：芯片上的微缩河道

在几十到几百微米宽的通道里操控纳升到皮升级的液体。这里有一个反直觉的物理现象，是整个领域的地基：

$$Re = \frac{\rho v l}{\mu} = \frac{惯性力}{粘性力}$$

微通道的特征长度 \(l\) 极小，所以雷诺数极低——**低雷诺数意味着层流**：两股水流可以肩并肩地流动而不混合，混合全靠分子扩散。

- **层流的好处**：流场完全可控，能做精确的浓度梯度、精确操控细胞和液滴；
- **层流的麻烦**：混合太慢，必须设计专门的微混合器（蛇形通道、混沌对流等）。

> **一个常见的课件勘误**：有的讲义把中文标注写反了。记住物理定义——**低 Re 是层流，高 Re 是湍流**，考试以公式和英文原文为准。

## 6.2 芯片实验室（Lab-on-a-Chip）

把实验室的完整流程压缩到一块芯片上：

```
采样 → 样品制备 → 混合反应 → 分离检测 → 信号读出
```

需要一整套微缩工具：微泵（推动液体）、微阀（开关流路）、微混合器（弥补层流混合慢）、检测单元（光学或电学读出）。应用上，POC（Point-of-Care，即时诊断）是最大场景——在病房、家庭、现场直接出结果，不等 centralized 实验室。

## 6.3 Top-down 与 Bottom-up：两种制造哲学

微纳制造有两种相反的思路：

| | Top-down 自上而下 | Bottom-up 自下而上 |
|---|---|---|
| 思路 | 从块体材料"雕刻"出结构 | 原子/分子自己"搭建" |
| 工具 | 光刻、刻蚀、沉积 | 自组装、化学/生物合成 |
| 优势 | 精度高、重复性好、IC 产业兼容 | 纳米级控制、可生物功能化、三维架构 |
| 局限 | 成本高、平面几何、材料不亲生物 | 大面积均匀性难、通量慢 |

实际项目常常**两者结合**：Top-down 做模具和电极，Bottom-up 做生物功能化（水凝胶修饰、纳米材料生长）。

## 6.4 软光刻：BioMEMS 的招牌工艺

第 2 章的光刻用紫外光和硬掩膜；BioMEMS 的主角是**软光刻**——用弹性体复制母模：

```
光刻做出 SU-8 母模（硅片上）
  → 浇注 PDMS 预聚物 → 固化 → 剥离 PDMS 复制品
  → 等离子处理表面 → 键合到玻璃/PDMS 上
  → 得到封闭微流控芯片
```

为什么 BioMEMS 挚爱 PDMS（聚二甲基硅氧烷）：便宜、透明（可显微镜观察）、易键合、生物相容，而且**透气**——活细胞要呼吸。代价是分辨率有限（大于 100nm）、会吸附疏水小分子、在有机溶剂里溶胀。

## 6.5 材料选择：四维权衡

选材料本质是在**性能—工艺—生物相容性—成本**之间权衡。用"什么场景选什么"来记最不容易忘：

| 材料 | 一句话画像 | 最适合的场景 |
|------|-----------|-------------|
| 硅 | 机械强、CMOS 兼容，但脆且贵 | 要和电路集成的器件 |
| 玻璃 | 透明、化学稳定、可复用 | 光学检测 |
| PDMS | 快、便宜、透气、易键合 | 快速原型、细胞培养 |
| PMMA（亚克力） | 可注塑、便宜、一次性 | 大规模量产的 POC 芯片 |
| SU-8 | 负性环氧胶、高深宽比 | 做母模和高结构 |
| 水凝胶 | 高含水、柔软、可降解 | 体内环境、药物缓释 |

注意 SU-8 是**负性**光刻胶，多用来做高深宽比的母模，不是器件本体材料。

## 6.6 器官芯片：药物研发的"芯片上的临床试验"

传统培养皿的局限：二维、静态、没有流体、没有组织结构。**器官芯片（Organ-on-a-Chip）**把这些都补上：

- 3D 组织界面；
- 流体剪切力（模拟血液流动）；
- 多细胞共培养；
- 机械拉伸（周期性刺激模拟呼吸、心跳）。

经典案例是**肺芯片**：上层种肺上皮细胞、下层种毛细血管内皮细胞，中间隔一层多孔膜；一侧腔室通空气，另一侧走培养液，周期性真空拉伸模拟呼吸运动。用途：环境毒素测试、吸入药物筛选、呼吸系统疾病建模——用人体细胞在芯片上做"临床试验"，替代部分动物实验。

## 本章记住三句话

1. 微流控的地基是雷诺数：微尺度下低 Re → 层流，两股流并行不混、混合靠扩散（低 Re=层流，别背反）。
2. 软光刻 = 光刻做 SU-8 母模 + PDMS 复制 + 键合；PDMS 便宜透明易键合还透气，是细胞培养首选。
3. 材料选择看四维（性能/工艺/相容性/成本）；器官芯片补上流体剪切力、3D 界面和动态刺激，是药物研发的新范式。
