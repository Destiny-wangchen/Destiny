# 第 2 章 · 芯片工厂：四大工艺循环

设计图纸再漂亮，也要有人把它变成硅片上的实物。这一章讲芯片的制造：它不是一次成型，而是**同一组工艺循环几十次**，一层一层把三维电路"盖"出来。

## 2.1 盖楼类比

把芯片制造想象成盖一栋超微缩的楼房：

1. **打地基**：拿一块高纯度单晶硅圆片（晶圆，Wafer），像做披萨的面饼；
2. **盖楼板**：在表面铺一层材料——金属当电线，绝缘层当楼板（沉积）；
3. **画图纸**：涂感光胶，用底片曝光，把图案"洗"上去（光刻）；
4. **雕刻**：把图案里多余的材料挖掉（刻蚀）；
5. **加佐料**：往指定区域掺杂质，让硅变成想要的半导体（掺杂）；
6. **回到第 2 步**，重复几十层。

四句口诀先背下来，后面每一步都围绕它展开：

> **光刻决定图案，刻蚀决定形状，沉积决定材料，掺杂决定电性。**

## 2.2 沉积：铺什么、怎么铺

沉积解决"材料从哪来"。主流方式有四类，选择逻辑是**要覆盖好还是质量好、能不能耐高温**：

| 方式 | 原理 | 特点 |
|------|------|------|
| 蒸发（PVD） | 加热金属让它气化，凝到晶圆上 | 简单，但像下雪——台阶背阴处盖不到（台阶覆盖率差） |
| 溅射（PVD） | 氩离子轰击靶材，把原子"撞"上去 | 膜均匀、附着好，**金属沉积的主流** |
| CVD | 两种气体在表面反应成膜 | 质量好、覆盖好；低压 LPCVD 纯度高（长多晶硅/氮化硅），等离子增强 PECVD 温度低（长绝缘层） |
| 热氧化 | 硅自己"长"出 SiO₂ | 不是铺上去的，是硅消耗着自己长出来的，界面最致密干净——栅氧化层专用 |

> **易错点**：热氧化不算沉积。蒸发和溅射同属 PVD，区别是"蒸发靠加热、溅射靠轰击"。

## 2.3 光刻：给芯片洗照片

光刻是把设计图案转移到晶圆上的核心步骤，也是芯片厂最贵的设备（光刻机）所在。流程五步：

```
涂胶 → 软烘 → 对准曝光 → 显影 → 后烘
```

原理和洗照片一样：晶圆上涂一层**光刻胶**（感光材料），透过掩膜版（底片）用紫外光曝光，再用药水（显影液）"冲"一遍。光刻胶分两种，方向完全相反：

| | 正胶（Positive） | 负胶（Negative） |
|---|---|---|
| 曝光后 | 变可溶，被洗掉 | 交联变硬，保留下来 |
| 记忆口诀 | **Whatever glows, goes**（照到就跑） | 照到就留 |
| 图形与掩膜 | 相同 | 相反 |

光刻三大指标：**分辨率**（能画多细）、**套刻精度**（几十层图案对得准不准）、**产能**（每小时几片）。先进工艺为什么用极紫外光（EUV，波长 13.5nm）？因为**光的波长决定能刻多细**——波长越短，分辨率越高，所以光刻机一路从可见光、深紫外走到极紫外。

## 2.4 刻蚀：往四周挖还是只往下挖

刻蚀解决"把不要的材料去掉"。分湿法和干法两大阵营，核心区别是**方向性**：

| | 湿法刻蚀 | 干法刻蚀 |
|---|---|---|
| 介质 | 液体化学试剂（如 BOE、KOH） | 气体等离子体 |
| 方向 | **各向同性**——四面八方一起腐蚀 | **各向异性**——主要向下腐蚀 |
| 后果 | 侧壁圆滑、有**钻蚀**（图案底下被掏空、线条变胖） | 侧壁笔直、能挖出高深宽比的结构 |
| 适用 | 高选择性、低成本、大面积 | 精细线条、垂直侧壁 |

现代芯片的互连线条必须笔直，所以精细刻蚀全靠干法。干法里的主力叫 **RIE（反应离子刻蚀）**：等离子体同时提供化学腐蚀和物理轰击，兼顾方向性与选择性。它的加强版 **DRIE（深反应离子刻蚀）**用"刻蚀与侧壁钝化交替"的博世工艺，能刻出深宽比超过 30:1 的垂直深槽——这是第 4 章 MEMS 加速度计、陀螺仪造质量块的关键设备。

## 2.5 掺杂：能量定深度，剂量定浓度

沉积和刻蚀做出了结构，掺杂决定每个区域的电学性格（P 型还是 N 型、多浓）。现代主流是**离子注入**：把杂质离子加速到高能，像打子弹一样"射"进硅片。

两个关键参数要记清：

- **能量（Energy）决定深度**——能量越高，打得越深；
- **剂量（Dose）决定浓度**——剂量越大，掺进去的杂质越多。

注入会打碎硅的晶格，所以注入后必须**退火**（900–1000°C 高温退火）：修复晶格损伤，同时让杂质原子落到晶格位置上真正"生效"。早期的掺杂靠高温扩散（杂质从高浓度区自然往低浓度跑），控制精度远不如离子注入，已被淘汰。

## 2.6 良率：灰尘是芯片的大敌

芯片特征尺寸只有几纳米，一粒灰尘落上去就可能导致短路或断路——这种致命缺陷叫**杀手缺陷**。缺陷来源包括：气相沉积时反应物先在气相里结成颗粒再飘落、刻蚀副产物颗粒挡住刻蚀造成"草状"缺陷等。

对策：超净车间（Class 1 洁净室，比手术室干净一千倍以上）、CMP 化学机械抛光、定期清洗腔体。**良率（Yield）直接决定成本**——一颗大芯片上有个坏点可能整颗报废，这也是第 7 章 Chiplet 拆小芯片的动机之一。

## 2.7 后段：切蛋糕、装盒子、验货

几十层循环做完，晶圆上密密麻麻排满了几百颗芯片。接下来：**划片**（Dicing，像切蛋糕一样切开）、**装架**（Die Attach，把裸片固定到基板上）、**引线键合**（Wire Bonding，用金线/铜线把芯片焊盘连到基板）、**封装**（Packaging，装进保护壳）、**测试**（Testing，挑出坏的）。MEMS 器件因为内部有可动结构，封装还要额外做气密保护，防止灰尘卡住微结构。

## 本章记住三句话

1. 芯片制造 = 沉积→光刻→刻蚀→掺杂的循环，重复几十层；口诀：光刻定图案、刻蚀定形状、沉积定材料、掺杂定电性。
2. 正胶"照到就跑"，湿法各向同性有钻蚀、干法各向异性侧壁直；精细结构靠 RIE/DRIE。
3. 离子注入"能量定深度、剂量定浓度"，注入后必须退火；良率是一切成本的核心。
