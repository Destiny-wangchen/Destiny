这是一份按"骗什么"编排的诡计谱系。

推理小说骗人的方式只有五层：骗空间、骗时间、骗人、骗语言、骗期待。这本书把近两百年里被用过的所有手法，按这五层拆开，逐层列尽，每一条给出可查的作品坐标。另有一章讲舞台与容器，一章讲那些结构上成立却几乎没人写透的空位。

它不写文学史，不评价流派高低，只做一件事：让你看清作者的手。

::: warning 剧透警告
全篇默认剧透。这是研究资料，不适合当读物。如果你只是想找几本书读，请先离开这一页。
:::
