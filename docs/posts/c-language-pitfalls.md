学期接近尾声，我把自己做题和考试中犯过的 C 语言错误翻出来重新过了一遍，从最大公约数、高精度除法，到闰年判断、星期计算，大大小小错过十几次。整理完发现，我的错误高度集中在几个地方，而且几乎每一个都是初学者的经典大坑。

与其让这些错误烂在错题本里，不如写出来给所有正在学 C 的朋友排排坑。下面每一条，都是我真实踩过的。

## 一、语法三件套，分号、括号、引号

最容易犯、也最不值钱的错误，往往让代码编译不过。

```c
a = -a        // 漏分号
ptintf("%d\n", b);   // 函数名拼错
if (a == C)   // 字符没加单引号，C 被当成未定义变量
if a == 'C'   // if 条件没加括号
```

正确写法如下。

```c
a = -a;
printf("%d\n", b);
if (a == 'C')
```

我还犯过一个更离谱的，把 Python 的习惯带进 C，写出 `if a=C:`、`else:` 这种带冒号的代码。C 语言没有冒号结尾这回事，而且判断相等必须用 `==`，单个 `=` 是赋值。混过其他语言的朋友要特别小心这个迁移坑。

**复习要点**，写完代码先扫一遍分号、括号、引号这三样。

## 二、scanf 和 printf，我错得最多的一类

这一类错误我犯了不下六次，堪称重灾区。

### 口诀，scanf 加 &，printf 不加 &

```c
scanf("%d %d", a, b);        // 错！漏了 &
scanf("%d %d", &a, &b);      // 对
printf("...%d...", &Y, &w);  // 错！多了 &，打印的是内存地址乱码
printf("...%d...", Y, day);  // 对
```

### 格式符要和变量类型一一对应

- 字符用 `char` + `%c`，别用 `%d` 去读字符
- `long long` 用 `%lld`
- `float`/`double` 用 `%f`

### scanf 格式串里千万别加 \n

```c
scanf("%d %d\n", &a, &b);  // 错！
```

格式串里的 `\n` 表示「跳过所有空白」，程序会卡住等你再输入一个非空白字符，在 OJ 上直接超时。这个坑我踩过一次就再也没忘。

### 输入带特殊符号时，把符号写进格式串

题目输入如果是 `16/19`、`1024*768 1` 这种，不能天真地用 `"%d %d"` 去读。

```c
scanf("%d/%d", &a, &b);
scanf("%d*%d %d", &h, &w, &m);
```

### 输出格式必须和样例逐字符一致

OJ 是逐字符比对的。我因为多输出了一句长句子、漏了句号、中文逗号打成英文逗号而判错过好几次。还有一次更冤，千辛万苦算出了答案 `day`，结果 printf 里打印了中间变量 `w`。

**教训是提交前把样例输出和自己的 printf 逐字符对照一遍，空格、标点、大小写、换行一个都不能差。**

## 三、变量不初始化，结果全靠运气

这个坑出现在区间累加、计数、分支判断等各种场景。

```c
int a, b, c, d;
d = d + c;   // d 是垃圾值，累加结果随机错
```

累加器、计数器必须初始化。

```c
int sum = 0;
int count = 0;
```

这可能是初学阶段出现频率最高的 bug。现在我每次写 `xxx = xxx + yyy` 之前，都会先问自己一句，它清零了吗。

## 四、几个让我印象最深的算法坑

### 高精度除法，余数乘 10 取商

输出 a/b 的小数（最多 200 位），我第一次写错得面目全非，该放大余数我放大了被除数，商和余数弄反，循环条件毫无意义导致死循环。正确的核心套路如下。

```c
printf("0.");
int r = a % b;               // 初始余数
for (int i = 0; i < 200; i++) {
    if (r == 0) break;       // 除尽提前结束，不补 0
    r *= 10;                 // 余数乘 10
    printf("%d", r / b);     // 输出商（这一位）
    r %= b;                  // 更新余数
}
printf("\n");
```

这个余数乘 10、取商、更新余数的循环值得默写三遍。

### 辗转相除法，三步交换加临时变量

我犯过的错，一是循环里用了输入的原始变量，没有用当前正在约分的变量，二是用 x、y 本身去算公约数，把要输出的原分子分母破坏掉了。正确写法如下。

```c
int tx = x, ty = y, t;       // 想保留原数，必须用临时变量去算
while (ty != 0) {
    t = tx % ty;
    tx = ty;
    ty = t;
}
// tx 就是最大公约数
```

还有两个特殊情况容易漏。分子为 0 时应输出 `0/1`；分母为负时分子分母要同时变号，保证分母为正。

### 数二进制里 1 的个数，别用除法数位数

我最早写 `a = a/2` 去统计，结果数出来的其实是「二进制位数」。7 的二进制是 111，有 3 个 1，我的代码数出 2。还有负数的坑，int 是 32 位补码，-1 的答案是 32 个 1，取负后再数就全错了。正确做法如下。

```c
unsigned int u = (unsigned int)a;  // 按补码位模式遍历
int count = 0;
while (u) {
    count += u & 1;
    u >>= 1;
}
```

进阶写法是 `while(u){ u &= u-1; count++; }`，每次消掉最低位的 1。

### 循环条件方向，先用样例推一遍

求最小 m 使 1+2+…+m ≥ n，我把条件写反了，写成了和够了还继续加，正确的方向是和不够才继续。

```c
int m;
for (m = 1; (m*m + m) / 2 < n; m++);
```

**教训是写循环条件之前，先拿样例手动推一遍方向，比如 n=100 时答案是 m=14。**

### 循环输出 26 个字母，while 后面忘加大括号

```c
while (...)
    printf("%c", c);   // 循环体只有这一句！
c++;                    // 更新语句在循环外 → 死循环
```

while 后面没加大括号，循环体只有一句 printf，更新语句根本没进循环，于是死循环打印同一个字母。而且像走到 Z 拐回 A 这种题，思路应该是固定循环 26 次，别让字符自己当条件，`'Z'+1` 是 `'['`，直接就退出了。

```c
for (int i = 0; i < 26; i++) {
    printf("%c", c);
    c++;
    if (c > 'Z' && c < 'a') c -= 26;
    else if (c > 'z') c -= 26;
}
```

### 大小写转换，三个错一起犯

- 用 `%d` 读字符 → 应该 `char c; scanf("%c", &c);`
- 一律 `+32`，没判断方向 → 小写转大写是 `-32`，大写转小写是 `+32`，非字母不变
- 用 `%d` 输出 ASCII 码 → 应该 `%c` 输出字符

### 温度转换，整数除法等于 0

`(b-32)*5/9` 里的 `5/9` 是整数除法，结果等于 0，整个表达式永远得 0。要写 `5.0/9.0`。另外题目要求保留 2 位小数就不要用 int，用 `float`/`double` 加 `printf("%.2f")`。

### 视频存储计算，int 溢出

计算 `1024*768*3*30*60`，结果是 42 亿，超过 int 上限 21.47 亿，输出直接变成负数。还有个更隐蔽的地方，只把接收结果的变量改成 `long long` 没用，表达式里前几个 int 相乘时就已经溢出了。正确做法是变量全用 `long long`（scanf/printf 用 `%lld`），或者第一步就强转。

```c
long long total = (long long)h * w * 3 * f * s;
```

**经验是看到乘积可能上千万、上亿，直接全上 long long 最稳。**

### 基姆拉尔森公式算星期，1、2 月要当成上一年的 13、14 月

```c
if (m <= 2) { m += 12; y -= 1; }
```

公式常数项（14 还是 15、要不要 +1）别背下来就信，拿样例年份验证一遍再提交。

## 五、选择题高频考点，短路求值加自增

`&&` 左边为假，右边不执行；`||` 左边为真，右边不执行。**短路时，右边的副作用（比如 `i++`）根本不会发生。**

考过这样几道真题。

- `j = !c && i++;`（c='A'，非零）时 `!c` 为假，短路，`i++` 不执行，结果是 `i=1, j=0`
- `a = (x++==2) && (y++==1);`（x=y=1）时后置自增是先比较后加，左边 `1==2` 为假短路，y 不加，结果是 `x=2, y=1, a=0`
- `z = x>y ? ++x : ++y;`（x=1, y=2）时条件为假只执行 `++y`，`++x` 不执行，结果是 `z=3`，x 不变

复习时按三步走，左边先算，再判断是否短路，最后看右边是否执行。

还有一个冷知识，不能作为 C 常量的是 `0582` 这种，以 0 开头是八进制，只能 0~7，含 8 非法。而 `0xA5`（十六进制）、`2.5e-2`（科学计数法）都合法。强制类型转换的标准写法是 `(double)x`，`double(x)` 是 C++ 写法。

## 六、我总结的错误模式，按频率排序

1. **scanf/printf 格式问题**（6+ 次），忘 &、多 &、格式符不匹配、格式串里加 `\n`、特殊分隔符、输出和样例不一致
2. **变量未初始化**（3 次），累加器、计数器忘了清零
3. **循环边界/条件方向**，条件写反、漏大括号、循环内不更新变量、死循环
4. **int 溢出与整数除法**，大数乘法用 `long long`；`5/9 == 0`、先乘后除
5. **算法理解偏差**，高精度除法、辗转相除、位运算数 1，这三个模板值得默写三遍
6. **短路求值 + 自增**，选择题必考
7. **特殊情况遗漏**，分子为 0、分母为负、余数为 0 提前退出、n=1 边界。写完主体逻辑后花 30 秒想想，输入取最小值、最大值和 0 时会怎样

## 七、考前（或提交前）10 分钟自查清单

- [ ] 每条语句有分号？if/else 条件有括号？没有 Python 冒号？
- [ ] `==` 不是 `=`？字符有单引号？
- [ ] scanf 全加 `&`，printf 全没加 `&`？
- [ ] 格式符和变量类型一一对应（%c/%d/%f/%lld）？
- [ ] scanf 格式串里没有 `\n`？输入里的 `/`、`*` 原样写进格式串？
- [ ] 累加器/计数器初始化为 0？
- [ ] 循环体有大括号？循环内变量有更新？条件方向和样例一致？
- [ ] 乘积可能很大？→ `long long`；要保留小数？→ `float`/`double` + `%.2f`；除法不能丢精度？→ `5.0/9.0`、先乘后除
- [ ] printf 内容和样例输出逐字符一致（空格、句号、中文标点、换行）？
- [ ] 想过边界没有，0、1、最大值、负数？
