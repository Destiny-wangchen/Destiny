> 不会打字之外任何电脑技能，也能 10 分钟看懂这篇。

## Markdown 到底是什么？

一句话：**打字时顺手加几个小符号，发布后文字自动变成好看的排版。**

举个例子，你在文章里写：

```text
**今天天气真好**
```

发布后，读者看到的就是 **今天天气真好**（加粗的）。就这么简单。

它不需要任何特殊软件——电脑自带的记事本都能写。你在这个网站的「写文章」页面里打的每一个字，用的就是 Markdown。下面这些符号，会一个就赚一个。

## 最常用的 6 个符号

### 1. 标题：文字前面加井号

```text
# 这是最大的标题
## 这是二级标题
### 这是三级标题
```

井号越多，标题越小，就像书里的「章 → 节 → 小节」。**注意：井号后面要空一格再写文字。**

一篇文章开头用一个大标题，中间用二三级标题分段，读起来就很有条理。

### 2. 加粗、斜体、删除线

| 你输入的 | 显示效果 | 用途 |
| --- | --- | --- |
| `**重要的话**` | **重要的话** | 强调重点 |
| `*轻轻地说*` | *轻轻地说* | 语气变轻 |
| `~~说过但反悔的话~~` | ~~说过但反悔的话~~ | 划掉 |

星号要紧贴着文字，中间不能有空格。

### 3. 列表：购物清单式写法

写「- 加空格」就是一条列表：

```text
- 苹果
- 香蕉
- 橘子
```

显示效果：

- 苹果
- 香蕉
- 橘子

想标顺序就用数字：

```text
1. 烧水
2. 下面
3. 三分钟后关火
```

想有子项目？在「-」前面敲两个空格，就变成子项。

### 4. 引用：别人说的好话

在句子前面加「> 加空格」：

```text
> 花园不需要很大，但要一直开花。
```

显示效果（左边会多一条竖线，一看就知道是引用）：

> 花园不需要很大，但要一直开花。

### 5. 链接和图片

**链接**：方括号写要显示的字，圆括号放网址：

```text
[我的 GitHub](https://github.com/Destiny-wangchen)
```

**图片**：比链接前面多一个感叹号：

```text
![一张风景照](图片的网址)
```

### 6. 分割线：三个减号

单独一行打三个减号：

```text
---
```

就会变成一条横线，用来把文章分成几大块。

## 换行的规矩（新手最容易懵的地方）

记住两句话就够了：

- **敲一个回车 = 换到下一行**（本站已经设置好，你敲回车读者就看到换行，所见即所得）
- **敲两个回车（空一行）= 新起一段**，段落之间才有呼吸感

## 进阶（可以不会，但了解一下）

**表格**：用竖线隔开就是表格，适合做对比：

```text
| 东西 | 价格 |
| --- | --- |
| 咖啡 | 20 |
| 茶 | 12 |
```

**代码框**：如果你要贴代码、命令，前后各打三个反引号（键盘 Esc 下面那个键），里面的内容会保持原样并变成等宽字体。

**想显示星号本身**（不变成加粗）？在星号前面加一个反斜杠 `\*`，它就老老实实显示为星号。

## 写完之后怎么发布

在这个网站上，流程简单到不像话：

1. 打开「写文章」页面（按标题下方的花锁点出来，如果你有权限的话）
2. 填标题、写正文——就用上面这些符号
3. 点「**一键发布**」

一分钟后，文章就在首页了。草稿还会自动存在浏览器里，写到一半关掉网页也不怕。

## 小结

| 符号 | 作用 |
| --- | --- |
| `#` | 标题 |
| `**文字**` | 加粗 |
| `*文字*` | 斜体 |
| `- ` | 列表 |
| `> ` | 引用 |
| `[字](网址)` | 链接 |
| `![说明](图片网址)` | 图片 |
| `---` | 分割线 |

先记住前三个就敢开始写了，其他的写两篇自然就会。写作最重要的是开始，不是语法。
