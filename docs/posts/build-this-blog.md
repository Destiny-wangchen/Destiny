> 这篇写给完全没碰过编程的朋友，全程不打一个专业术语的哑谜。
> 如果你只是想**在这个网站上写文章**，其实不用看这篇——打开「写文章」页面点一键发布就行。这篇是写给想拥有一个**完全属于自己**的网站的人。

## 先打个比方，弄懂三样东西

想象你想在城里开一家自己的小书店，需要什么？

**1. 书稿 —— Markdown 文件**

你写的文章就是书稿。Markdown 是一种「打字时顺手加几个小符号」的写作方式，比如在字两边打两个星号，发布后那段字就自动加粗。写文章和写 Word 没区别，只是多了几个小符号。

**2. 一块免费的地皮 —— GitHub**

GitHub 是一个全球程序员都在用的「网盘 + 仓库」，免费。你可以把自己的所有文件存上去，它还会帮你记录每一次修改（改错了随时能退回上一步）。

**3. 免费装修并开放参观 —— GitHub Pages**

光有仓库还不够，得让别人能打开你的网站。GitHub 自带一项叫 Pages 的免费服务：你说一声「把我仓库里的博客开放出去」，它就自动帮你生成一个网址，全世界都能访问。

所以整个流程就是：**写书稿 → 存进仓库 → 一键开放**。没有租金，没有服务器，不用求人。

## 动手前的准备（只需要做一次）

1. **注册一个 GitHub 账号**：打开 github.com，点 Sign up，填邮箱密码，跟注册任何网站一样
2. **在你的电脑上装 Node.js**：它是「印刷机」，负责把你的书稿变成能打开的网页。去 nodejs.org 下载安装包，一路点「下一步」装完就行
3. **认识一下「命令行」**：Windows 上按 Win 键输入 powershell 回车，会弹出一个黑底（或白底）的窗口。别怕，它就是「用打字跟电脑对话」的窗口，下面让你输入什么就复制粘贴什么

## 五步搭好博客

### 第 1 步：从模板开始

从零造房子太累，先用现成的毛坯房。把这个仓库（github.com/Destiny-wangchen/Destiny）下载到你电脑上，或者按它的结构新建文件夹。目录大概长这样：

```text
我的博客/
├── docs/
│   ├── index.md        ← 首页内容
│   ├── posts/          ← 你的所有文章，一篇一个文件
│   └── .vitepress/     ← 网站的「设置」，一般不用动
└── package.json        ← 项目说明书
```

### 第 2 步：把它跑起来看看

在博客文件夹里打开命令行，输入两行字：

```bash
npm install    ← 第一次要等几分钟，下载各种零件
npm run dev    ← 启动！
```

然后浏览器打开它提示的网址（一般是 localhost:5173），就能看到你的博客了。**改文件保存，网页自动刷新**，跟编辑实时预览一样。

### 第 3 步：写你的第一篇文章

打开 `docs/posts` 文件夹，新建一个文本文件改名为 `my-first-post.md`（注意后缀是 .md 不是 .txt），用任何文本编辑器打开，开头写上这几行：

```text
---
title: 我的第一篇文章
date: 2026-09-12
tags:
  - 生活
---

从这里开始写正文……
```

上面三横线之间的部分是「文章的档案卡」：标题、日期、标签。保存后刷新网页，首页自动就会出现这篇文章——**不用改任何代码**。

### 第 4 步：上传到 GitHub

在 GitHub 网页上点 New repository（新建仓库），起个名字。然后在博客文件夹的命令行里：

```bash
git add -A                    ← 把所有文件打包装车
git commit -m "第一次上架"     ← 贴个标签说明这次改了什么
git push                      ← 发车，推到 GitHub
```

第一次推会要求登录，跟着提示操作就行。

### 第 5 步：打开「开放参观」的开关

回到 GitHub 网页，进入你的仓库：

**Settings → Pages → Source 选 GitHub Actions**，保存。

再去仓库里加一个「自动部署」的配置文件（告诉 GitHub：每次我上传，你就自动重新生成网站）。这个博客仓库里的 `.github/workflows/deploy.yml` 就是现成的，抄过去能用。

以后每次 `git push`，一分钟左右网站自动更新。完事。

## 常见问题

**要花钱吗？** 不用。GitHub 账号、Pages 托管、Node.js 全部免费。

**要学编程吗？** 日常写文章完全不用。上面出现的命令复制粘贴就行，理解成「咒语」也无妨——念了就生效。

**能换成自己的网址吗？** 能。GitHub Pages 支持绑定自定义域名，设置里加一下就行，域名一年几十块（不买也完全能用免费网址）。

**文章写错了/误删了怎么办？** 这就是用 GitHub 的好处——它记得每一次修改，随时能找回任何一版。

## 最后

这套东西搭好之后，你拥有的就是：一个**完全属于自己的、加载飞快的、永久免费的**小站。写作这件事，从此只和文字有关。
