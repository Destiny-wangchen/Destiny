一份写给**学过 C、但一遇到段错误、乱码、端口被占用就卡住**的人的诊断记录。每一篇是一个真实症状，按"主诉 → 问诊 → 查体 → 化验 → 诊断 → 处方"走一遍，最后落到几条能带走的工程习惯。

- 每篇配一个能直接跑的实验，全部在 Windows + Dev-C++ 自带 MinGW 上实测过，文中的地址、退出码都是真实输出
- 不默认你懂体系结构，但也不怕你懂：该给数字的地方给数字（栈多大、对齐几字节、Cache Line 多宽）
- 和[C 语言例题册](/cbook/)互补：那边练"怎么写对"，这边看"为什么这么写"

## 建议的读法

1. 先照着正文把实验跑一遍，看到真实输出再看结论，比自己脑补一遍有效得多；
2. 每篇最后的"处方"可以单独抄出来，当排错清单用；
3. 遇到崩了但不知道从哪查的，按"编译期 → 链接期 → 运行期 → 逻辑错 → 超时"五类先归类，第 07 篇会专门讲这个。
