## 主诉

判断两个矩形的面积是不是相等，代码是这么写的：

```c
if (w1 * h1 == w2 * h2)
    printf("面积相同\n");
```

输入 `0.1 0.3` 和 `0.3 0.1`，两个面积都是 0.03，判断却走了 else。改成 `0.2 0.3` 和 `0.1 0.6`，一样判不等。

这种题目最气人的地方是：纸上算出来明摆着相等，程序就是不认。

## 化验

```c
#include <stdio.h>
#include <float.h>

int main(void)
{
    double s = 0.1 + 0.2;
    printf("0.1 + 0.2 = %.20f\n", s);
    printf("0.3       = %.20f\n", 0.3);
    printf("s == 0.3  ? %d\n", s == 0.3);

    float f = 16777216.0f;
    printf("f     = %.1f\n", f);
    printf("f + 1 = %.1f\n", f + 1);
    return 0;
}
```

实测输出：

```text
0.1 + 0.2 = 0.30000000000000004000
0.3       = 0.29999999999999999000
s == 0.3  ? 0
f     = 16777216.0
f + 1 = 16777216.0
```

两个数差了不到 6×10⁻¹⁷，相等判断就是假。`16777216 + 1` 干脆等于自己，加了个寂寞。

## 诊断：二进制小数能表示的，只是 2 的负幂次之和

十进制里 1/3 写成 0.3333... 永远写不完，机器里也一样：0.1 在二进制中是无限循环小数，`double` 只能截到第 53 位，剩下的丢掉。0.1 存进去的那一刻就已经不是 0.1 了，只是最接近 0.1 的那个二进制数。

`double` 的结构是 1 位符号、11 位阶码、52 位尾数有效数字，大约能表示 15～16 位十进制有效数字。`float` 尾数只有 23 位，约 7 位十进制。

所以第一行输出里，0.1 + 0.2 得到的是 `0.30000000000000004000`，而字面量 0.3 存的是 `0.29999999999999999000`。它们不等，但差得极小。

`16777216.0f + 1` 为什么等于自己？`float` 尾数 23 位能精确表示的最大连续整数是 2²⁴ = 16777216。比它大的整数之间至少隔 2，加 1 落在两个可表示值中间，只能就近取，于是回到原值。这也是为什么用 `float` 存时间戳、金额、身份证号一定会出事。

## 一个常用的错误写法

知道了不能用 `==`，很多人改成 `if (fabs(a - b) < 1e-6)`。这个写法在大多数题目里能用，但它有前提：**a 和 b 的量级在 1 附近**。

如果两个数都是 10¹⁵ 量级，它们 1 的差别根本存不进尾数，`1e-6` 的阈值就毫无意义；如果两个数都是 10⁻¹⁰ 量级，任何两个不同的数都会满足小于 `1e-6`。稳妥的写法是相对误差：

```c
int nearly_equal(double a, double b, double eps)
{
    double diff = fabs(a - b);
    double scale = fmax(fabs(a), fabs(b));
    if (scale < 1.0) scale = 1.0;       /* 都接近 0 时退回绝对误差 */
    return diff <= eps * scale;
}
```

竞赛题里更常见的做法是题目直接说"误差不超过 10⁻⁶ 即算正确"，那你就按题目给的阈值来，不用自己发明。

## 处方

1. 金额一律用整数存分。`1999` 表示 19.99 元，加减不会丢精度，输出时再拆小数点。这是唯一能彻底避免小数误差的办法。
2. 需要比较就定阈值，并跟着题目走。没有题目约束时用相对误差，不要裸用 `1e-6`。
3. 别用浮点做循环计数器和下标。`for (double x = 0; x != 1.0; x += 0.1)` 这种循环可能永远不结束。
4. 打印要还原就用 `%.17g`。`printf("%f")` 默认只给 6 位小数，看着像精度问题，其实只是没打全。
5. `float` 只用在明确够用的场景，比如图形和嵌入式；一般计算默认 `double`，别为了省 4 字节换来 7 位有效数字。

## 复诊

浮点误差在题目里最常见的两种变体，一是"输出保留两位小数"（这里还要注意四舍五入和 C 的舍入方向），二是"判断坐标是否在圆上"。去 [第 1 章](/cbook/01-hello.html) 的温度换算和 [第 2 章](/cbook/02-fenzhi.html) 的几何判断里各找一道，把 `==` 换成阈值再跑一遍，感受会很直接。
